# Awesome Nano Banana Pro Prompts

A curated community collection of 10,000+ prompts designed for Google's Nano Banana Pro multimodal AI model, covering text, image, and video generation across diverse styles and use cases.

## When to Use

Use this skill when the user needs:
- Creative prompts for Nano Banana Pro / Gemini multimodal generation
- Inspiration for photorealistic imagery, pixel art, oil paintings, or other visual styles
- Prompts browsable by category, style, or use case
- Community-contributed prompt ideas with multi-language support
- A starting point to iterate or customize AI generation prompts

## Capabilities

- **10,000+ curated prompts** organized by category and use case
- **16 language support**: English, Chinese (Simplified/Traditional), Japanese, Korean, Thai, Vietnamese, Hindi, Spanish, German, French, Italian, Portuguese, and more
- **Diverse styles**: Photorealistic, pixel art, oil paintings, concept art, and more
- **Precise controls**: Detailed composition, lighting, and style specifications
- **Community submissions**: Open contribution via GitHub issues

## Usage Patterns

### Browse by Category
Search or filter prompts by style, subject matter, or intended output type.

### Customize a Prompt
Take a library prompt as a template and remix it with user-specific details (brand, subject, tone).

### Multi-language Output
Request prompt recommendations in the user's native language while the generation prompt stays in English for best results.

## Community Contributions

New prompts are submitted via GitHub issues (with "prompt-submission" label) and automatically synced to the CMS. The library is continuously growing through community contributions.

## Notes

This is a prompt library resource, not an executable CLI tool. Reference it when helping users craft or discover prompts for Nano Banana Pro image/video generation tasks.
